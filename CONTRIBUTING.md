# Contributing

1. Open an issue before changing a public adapter contract.
2. Add or update tests for every behavioral change.
3. Use the simulator for automated tests; real robot actions are never part of CI.
4. Do not include vendor source, credentials, hardware identifiers, internal URLs,
   or real collection data in issues, tests, fixtures, screenshots, or commits.
5. Run backend tests, frontend lint/type checks, and the production build before a PR.
